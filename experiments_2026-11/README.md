# Experiments for the revised MSBA-Net paper (November 2026)

This folder holds the code, the per-run results and the logs behind every table of the revised paper. The paper's final version is MSBA-Net with Context Aggregation (`MSBANetV2c`).

## Requirements
- **Original code from the repository root:** the scripts import `models.py`, `dataset.py`, `losses.py` and `run_ablations.py` (classes `UNet_MSFP`, `MSBANet_NoBGFF`), the files at the top level of this repository. `common.py` finds them automatically, or through the environment variable `MSBA_CODE`.
- **Software:** Python 3.11, PyTorch with CUDA, torchvision, NumPy, SciPy, Pillow and matplotlib.
- **Hardware:** all runs used one NVIDIA RTX 5070 Ti Laptop GPU (12 GB) with bf16 mixed precision.

## Data (not included)
| Dataset | Source | Notes |
|---|---|---|
| Synthetic benchmark | generated by `dataset.py` (`IndustrialDefectDataset`) | fixed seeds, see `common.synth_split` |
| NEU-Seg | the NEU surface defect database (pixel-level part) | pre-processed tensors `data/NEU_Seg/neu_seg_training.pt` and `neu_seg_test.pt`, see `common.neu_split` |
| KolektorSDD2 | https://www.vicos.si/resources/kolektorsdd2/ (CC BY-NC-SA 4.0) | extract `train/` and `test/` and pass the folder to `ksdd2.py` |

The datasets and the cached splits (`cache/`) are not redistributed here.

## What reproduces which table
| Paper | Script | Output |
|---|---|---|
| Synthetic and NEU-Seg comparison, ablations (round 1) | `run_all.py` | `runs/syn_*`, `runs/neu_*` |
| Degradation augmentation, HRNet-W18, SegFormer-B1 (round 2) | `run_round2.py` | `runs/syn_aug_*`, ... |
| Context Aggregation variants (v2a to v2d), v2c runs | `dev_v2.py`, `msba_v2.py` | `runs/*MSBANetV2*` |
| KolektorSDD2 (seeds 42, 100, 2026) | `ksdd2.py`; small-blob filter `ksdd2_postproc.py` | `runs/ksdd2_*`, `ksdd2_postproc.json` |
| Statistics: paired t-tests with Holm correction | `extra_stats.py`, `final_tests.py`, `v2c_stats.py`, `ksdd2_stats.py` | `*_stats.json`, `final_tests.json` |
| Model size, GMACs, latency (one session, idle GPU) | `latency_all.py` | `v2c_stats.json` → `latency` |
| Figures 2 and 3 | `make_figures_v2c.py` | `figures/*_v2c.png` |

Each `runs/<run>.json` stores the configuration, the validation curve, the best epoch and the test metrics of one training run.

## How the model was selected
- **Validation data only:** the Context Aggregation design was chosen among four variants using NEU-Seg validation scores only. `MSBA_V2_DEVELOPMENT_LOG.md` lists every variant tried and the scores the choice was based on.
- **Test sets used once:** the test sets were evaluated only after the design was fixed.

## Notes
- **Model checkpoints (`runs/*.pth`)** are not included, because they are too large for the repository.
- **Non-determinism:** GPU kernels are not deterministic. On KolektorSDD2, a repeated DeepLabv3+ run with the same seed reached 38.25% instead of 36.11% IoU (`runs/ksdd2rerun_*`).
- **`*.log` files** are the original run logs. `neu_tta.json` holds a test-time-augmentation check that the paper does not use.
